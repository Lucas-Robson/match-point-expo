# Registro de decisões técnicas

Esta pasta guarda decisões que afetam mais de uma área do MatchPoint.

Use `000-modelo.md` como base. Numere os novos registros em sequência:

```text
001-escolha-do-banco.md
002-modelo-de-autenticacao.md
003-estrutura-de-navegacao.md
```

Situações possíveis: `proposta`, `aceita`, `substituída` ou `rejeitada`.

Uma decisão aceita não deve ser alterada apenas pela edição do documento original. Crie um novo registro explicando por que ela foi substituída.
