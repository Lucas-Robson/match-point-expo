# Match Point — Expo

Aplicativo Expo para Android, iOS e web.

Inclui abertura, login, recuperação de senha, escolha de perfil, cadastros de atleta/treinador/instituição/responsável, área do atleta em duas etapas, painéis de atleta e treinador, notificações e conteúdo Mulheres no Esporte.

## Antes de contribuir

Pessoas devem ler o [Manual de colaboração](docs/MANUAL_DE_COLABORACAO.md). Ferramentas de IA devem começar pelo arquivo [`AGENTS.md`](AGENTS.md), que torna obrigatórios os limites de cada área e direciona para os documentos necessários. O repositório também possui arquivos de entrada equivalentes para GitHub Copilot, Claude, Cursor e Gemini.

Documentos principais:

- [Manual de colaboração](docs/MANUAL_DE_COLABORACAO.md)
- [Contratos de dados](docs/CONTRATOS_DE_DADOS.md)
- [Registro de decisões técnicas](docs/decisoes/README.md)

```bash
npm install
npx expo start
```

Escaneie o QR Code com o Expo Go ou pressione `w` para abrir no navegador.
